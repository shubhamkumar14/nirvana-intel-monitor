Last Mile Delivery Program
One80 provides market leading last mile delivery coverage for residential furniture and appliance delivery services with some assembly and installation exposure. With over two decades of experience, our transportation specialists maintain underwriting authority with multiple carrier partners.

Targeted Classes
The target classes we focus on for this program are:
Residential furniture delivery
Residential appliance delivery
Established operations
New ventures
Available Coverages
The available coverages we have to offer for this program are:
Auto Liability
General Liability
Physical Damage
Cargo
Occupational Accident (quotes offered separately)
Workers’ Compensation (quotes offered separately)
Key Features
The key features of this exclusive program include:
All auto policies are scheduled unit and named driver.
Amazon DSPs and small package delivery operations do not qualify for this program.
Maximum unit size is 33,000 GVW.
No PPV size units can be written in this program.
We are not able to write in NY or MA. This includes if any units are registered in these states.
The max GL limits we can offer is $1m/$2m. The max Auto limit we can offer is $1mm.
Submission Requirements
The submission requirements of this exclusive program are:
Program app (**Application varies by size of account, please inquire prior to submitting)
Last Mile Supplemental (Please inquire before submitting)
Vehicle list template completed in XLS – including full garaging street address for all units
Driver list template completed in XLS
MVRs for all drivers and owners (even if they do not drive)
IC agreement – if HNO coverage is requested
Currently valued loss history for the four prior years for all lines being quoted, if prior coverage
If no prior coverage, signed NKLL is required.
Completed Summary of Experience form or resume for the owner for all accounts with less than three year’s document prior loss history
Copy of insurance requirements needed
List of any AI’s needed, including form# needed
Copy of vehicle registrations for all units
